# Student Planner

A command-line task planner for students, written in Python as a project for CSC 111 at King Saud University.

## Features

- Add, edit, and delete tasks
- Find a task by ID or search by title keywords
- List all tasks, or filter by course or priority
- Mark tasks as completed
- Progress summary with completion percentage
- Input validation (DD/MM/YYYY dates with leap-year handling, priority levels, task IDs)

## How to run

1. Install Python 3.
2. Download `student_planner.py`.
3. Run:

   python student_planner.py

4. Choose an option from the menu (1-11).

## Notes

Tasks are stored in memory only, so they are cleared when the program exits. Saving tasks to a file is a possible future improvement.
